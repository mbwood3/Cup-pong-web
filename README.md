# Cup-pong-web
New cup pong game

---

## How to play (no Node.js required)

1. Open the `Cup-pong-web` folder in File Explorer.
2. Double‑click **`game.html`**.
3. The game opens in your browser. **Swipe** (phone/tablet) or **click‑and‑drag** (desktop) to throw the ball. Use **Reset Ball** to try again.

Cups use the placeholder logos in `public/logos/`. Replace those files with your own images to use your logos.
